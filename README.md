# 方块街机 · Puzzle Arcade

纯前端解谜游戏集。首页直接进入数织，点击「游戏大厅」可浏览已收录的游戏。

## 本地运行

需要 Node.js 20 或更新版本。在项目目录运行 `npm run dev`，浏览器打开 http://127.0.0.1:5173 。无需安装依赖。运行 `npm test` 验证题库和数织规则。

要用同一 Wi-Fi 下的手机试玩，可在 PowerShell 中先设置 `$env:HOST = '0.0.0.0'`，再启动服务，用手机访问电脑的局域网 IP 和端口 5173。

## 数织

每个数字代表一段连续填色的格数，相邻两段至少隔一格。根据行列提示还原图案即可通关。可以点按或拖动绘制，鼠标右键标叉。用 Tab 进入棋盘后，可用方向键移动、空格使用当前工具、X 标叉、Delete 擦除。浏览器会保存当前关卡进度。

在「新局设置」中选择 5×5、10×10 或 15×15 棋盘，以及简单、中等或困难难度，点击「新开一局」即可应用。「换一题」沿用当前棋盘的尺寸和难度，「重置」清空当前题的作答。

随机关卡在浏览器的 Web Worker 内生成。生成器从候选图案提取提示，枚举各行、各列满足提示的填法，只填写所有可行填法都一致的格子，再把结果传给交叉方向的提示。只有全部格子都能由此确定的题目才会出题，因此每题都具有唯一解，且全程可以逻辑推导。难度按完成推理所需的轮数划分，同一尺寸下，困难题需要更多轮行列交叉推理。

## 扩展游戏集

页面使用原生 Web Components 和 ES Modules。大厅从 `src/app.js` 的游戏注册表生成条目，并通过 URL 哈希切换游戏。数织的题库和纯规则位于 `src/puzzles.js`，棋盘交互在 `src/nonogram.js`。

添加游戏时，新建自定义元素并注册名称、入口、图标和玩法说明。当前操作面板服务于数织，玩法不同的游戏可在页面组件的游戏视图中接入自己的面板。共享导航、游戏大厅和基础视觉样式可继续使用。
