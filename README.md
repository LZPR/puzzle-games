# 方块街机 · Puzzle Arcade

纯前端解谜游戏集。首页直接进入数织，点击「游戏大厅」可浏览已收录的游戏。

## 本地运行

需要 Node.js 20 或更新版本。在项目目录运行 `npm run dev`，浏览器打开 http://127.0.0.1:5173 。无需安装依赖。运行 `npm test` 验证题库、解谜规则和生成器。

要用同一 Wi-Fi 下的手机试玩，可在 PowerShell 中先设置 `$env:HOST = '0.0.0.0'`，再启动服务，用手机访问电脑的局域网 IP 和端口 5173。

## 数织

每个数字代表一段连续填色的格数，相邻两段至少隔一格。根据行列提示还原图案即可通关。可以点按或拖动绘制，鼠标右键标叉。用 Tab 进入棋盘后，可用方向键移动、空格使用当前工具、X 标叉、Delete 擦除。浏览器会保存当前关卡进度。

在「新局设置」中选择 5×5、10×10 或 15×15 棋盘，以及简单、中等或困难难度，点击「新开一局」即可应用。「换一题」沿用当前棋盘的尺寸和难度，「重置」清空当前题的作答。

随机关卡在浏览器的 Web Worker 内生成。生成器从候选图案提取提示，枚举各行、各列满足提示的填法，只填写所有可行填法都一致的格子，再把结果传给交叉方向的提示。只有全部格子都能由此确定的题目才会出题，因此每题都具有唯一解，且全程可以逻辑推导。难度按完成推理所需的轮数划分，同一尺寸下，困难题需要更多轮行列交叉推理。

## LITS 四格拼图

从「游戏大厅」打开 LITS，也可以直接访问 `#lits`。每个粗线围成的区域恰好填四格，拼成 L、I、T、S 中的一种。形状可以旋转或翻转。全部填色格必须共边连成一片，不能填满任何 2×2 方块，不同区域中同种形状的填色格也不能共边。

可以选择 6×6 或 8×8 棋盘，以及普通或困难难度。操作方式与数织相同，两种游戏各自保存当前关卡进度。

生成器先随机放置四格形状，再从这些形状向外扩展区域。若初始尝试未找到符合要求的棋盘，就从经过验证的布局出发，随机调整区域边界。每道题都由求解器确认只有一个符合规则的解。求解器枚举各区域的可行填法，每遇到一次需要尝试多种填法的选择就记为一次分支。普通题少于 4 次分支，困难题至少 4 次。

## 扩展游戏集

页面使用原生 Web Components 和 ES Modules。大厅从 `src/app.js` 的游戏注册表生成条目，并通过 URL 哈希切换游戏。数织和 LITS 的棋盘组件分别位于 `src/nonogram.js` 和 `src/lits.js`，点按、拖动和键盘输入共用 `src/grid-game.js`。数织的题库和纯规则位于 `src/puzzles.js`。

数织和 LITS 共享导航、大厅、状态栏、操作面板和新局设置。添加同类游戏时，可注册游戏名称、入口、图标、玩法和设置选项，并让棋盘组件提供 `newPuzzle(size, difficulty)`、`command(command)` 以及冒泡的 `game-state` 事件。
